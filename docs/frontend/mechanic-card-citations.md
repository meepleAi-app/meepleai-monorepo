# Mechanic Card Citations — Rich Inline-Citation UX (ME-M2.1, #530)

Parent ADR: [ADR-051](../for-claude/architecture/adr/adr-051-*.md). Backend contract:
`GET /api/v1/games/{sharedGameId}/card` → `PublishedMechanicCardDto`.

This is the frontend for the tooltip citation badge + responsive PDF source panel +
"copy as quote" flow on the public, login-gated mechanic card
(`/games/[id]/card` → `MechanicCardView`).

> Path note: this lives under `docs/frontend/` per the #530 task brief. The wider repo
> convention for developer docs is `docs/for-developers/frontend/`.

## Components

| Component | Path | Responsibility |
|---|---|---|
| `MechanicCitationBadge` | `apps/web/src/components/features/mechanic-card/MechanicCitationBadge.tsx` | The inline `[p.N]` badge. Radix tooltip preview of the quote on hover/focus; activates the panel on click / Enter / Space. |
| `MechanicCitationPanel` | `apps/web/src/components/features/mechanic-card/MechanicCitationPanel.tsx` | The responsive source panel (desktop `Sheet` / mobile `Drawer`). Header + highlighted PDF + copy/report footer + clipboard-fallback modal. |
| `PdfQuoteViewer` | `apps/web/src/components/pdf/PdfQuoteViewer.tsx` | Presentational PDF body: renders the page, highlights the quote, shows the "not found" fallback banner. Shared by BOTH the admin `PdfQuoteHighlighter` Dialog (#526) and the public panel. |
| `citation-format` (utils) | `apps/web/src/lib/mechanic-card/citation-format.ts` | Pure helpers: `truncateAtWordBoundary`, `formatApaCitation`. |

`MechanicCardView` renders one `MechanicCitationBadge` per citation and a **single**
`MechanicCitationPanel` instance (AD-2). Clicking another badge swaps the panel's
content rather than opening a second panel.

### DTO fields consumed (#530 additions)

The card DTO (`mechanic-card.schemas.ts`) gained three fields used only by the APA output:

- `sourceAnalysisId` — guid, always present (from the content snapshot).
- `publicationYear` — `int | null` (SharedGame; `null` → `[n.d.]`).
- `documentName` — `string | null` (source PDF title/filename; `null` → `Rulebook`).

## The APA "copy citation" format (AC-3)

`formatApaCitation(...)` emits exactly:

```
{publisher}. ({year}). {gameTitle}: {documentName} (p. {pdfPage}).
[Excerpt]: "{quote}"
Generated by MeepleAI mechanic extractor (analysis_id={uuid}).
```

Fallbacks (each unit-tested):

| Missing field | Substitution |
|---|---|
| `publisher` (null/blank) | `[publisher unknown]` |
| `publicationYear` (null) | `[n.d.]` |
| `documentName` (null/blank) | `Rulebook` |
| `pdfPage` (null) | `n/a` |
| `quote` (null/blank) | empty excerpt (`"[Excerpt]: """`) |

`truncateAtWordBoundary(text, maxWords = 25)` returns the text unchanged when it has
≤ `maxWords` words, otherwise the first `maxWords` words joined with `' '` plus a single
`…`. It never splits a word and collapses internal whitespace.

## The responsive panel

- **Desktop (≥768px)** → right-hand `Sheet` (~480px), via `@/components/ui/sheet`.
- **Mobile (<768px)** → bottom `Drawer` (90vh), via `@/components/ui/drawer/drawer`
  (vaul-backed on mobile).
- The breakpoint is read with `useMediaQuery('(min-width: 768px)')`; **exactly one**
  surface is rendered so pdfjs mounts once.
- **PDF**: `PdfQuoteViewer` (→ `PdfInlineViewer`) keeps pdfjs lazy (`next/dynamic` worker
  URL); nothing here imports pdfjs eagerly.
- **a11y**: the Sheet/Drawer primitives provide the focus trap + ESC-to-close. The panel
  also (a) restores focus to the badge that opened it on close, and (b) announces the open
  via an `aria-live="polite"` region.

## Failure-mode matrix

| Condition | Behaviour |
|---|---|
| Quote > 25 words | Tooltip shows the first 25 words + `…`. |
| `citation.pdfPage == null` | Badge is disabled (~60% opacity, non-interactive); tooltip reads "Pagina non disponibile"; no panel opens. |
| `citation.quote` missing/blank | Tooltip shows `[Citazione regolamento p.{N}]`; APA excerpt is empty. |
| Quote not locatable in the PDF text layer | `PdfQuoteViewer` shows the amber "verifica manualmente" fallback banner (`data-testid="pdf-quote-fallback"`); the page still renders. |
| PDF fetch fails | `PdfInlineViewer` renders its own error state; the panel chrome + copy still work. |
| `navigator.clipboard` present, `writeText` resolves | APA string copied + `sonner` toast "Citazione copiata". |
| `navigator.clipboard` absent | Fallback modal: pre-selected read-only `<textarea>` + "Premi Ctrl+C per copiare". |
| `navigator.clipboard` present, `writeText` rejects (permission) | Same fallback modal (no toast). |
| "Segnala errore" button | Inert placeholder (M3.1 not built): disabled, with an explanatory `title`. |
