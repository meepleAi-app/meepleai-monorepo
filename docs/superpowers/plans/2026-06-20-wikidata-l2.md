## Anti-patterns to avoid

- ❌ **Re-implementing components that already exist** — Phase 0 audit must verify as-shipped BEFORE writing new code
- ❌ **Adding new DLQ table** — riusa esistente `wikidata_cover_enrichment_attempts` (DEC-3l)
- ❌ **Adding ScheduledAttemptCount / LastError columns** — `RetryCount` + `Details` sufficient
- ❌ **Persisting circuit-breaker state in DB** — runtime Polly handler only (DEC-3l-1)
- ❌ **Multi-pod rate-limiter (Redis)** — DEC-3e single-pod constraint stays; defer until HPA=1 lifted
- ❌ **Keeping ImageSharp 3.x (Six Labors Split License)** — DEC-3d-1 LOCKED on Magick.NET migration
- ❌ **Downgrading to ImageSharp 2.1.x (EOL upstream)** — security patches only on 3.x branch, audit risk
- ❌ **Re-implementing Cache-Control logic** — already shipped, Phase 4 DESCOPED
- ❌ **Skipping WireMock contract tests** — Crispin C-002 gap closure mandatory for Phase G
- ❌ **Rendering attribution footer for non-game entities** — Wikidata enrichment is `entity === 'game'` only
